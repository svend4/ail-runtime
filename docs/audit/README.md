## Сводка (executive summary)

**Что это.** AIL Runtime — исследовательский прототип «семантического слоя»: код как бинарный AST, ownership-модель, безопасный hot-swap с lineage, визуальный алфавит рёбер Star Gate, шестиугольник доменов GERMES, трёхуровневая шкала связности D1/D2/D3 с «насыщенностью», метрики здоровья графа (marginality, lever balance), виртуальная клавиатура и шрифты Solan для M2M-записи.

**Стадия.** Концепт — оригинальный, многослойный, но *эвристический*: физические и комбинаторные аналогии (jamming, Рамсей) используются как метафоры, а не как формальные результаты. Реализация — демонстрационный прототип (pre-MVP): 30 коммитов за один день (2026-07-23), один слабый тест, CI отсутствует, библиотека в текущем виде **не собирается**.

**Ключевые находки (подробности и доказательства — в 02-technical.md):**

1. `cargo build` падает с 13 ошибками: `vizgraph.rs` и `lever.rs` ссылаются на крейт по его собственному имени (`ail_mvp::`) изнутри крейта.
2. Модули «шагов 1–5» (`actor_with_graph.rs`, `viz_demo.rs`) не подключены к бинарнику и **никогда не компилировались**: при подключении — две ошибки компиляции. Статус «✅» в `IMPLEMENTATION_STATUS.md` не подтверждается.
3. Формула насыщенности анти-монотонна по весу: усиление ребра (`reinforce +5`) **понижает** его насыщенность с 0.500 до 0.143 (D2 → D1). Документация утверждает обратное.
4. D3 недостижим топологически для клик меньше K₆; демо «ожидаем Critical/High» для `Transfer ✕ Refund` выдаёт `Low / Allowed`.
5. Проверка риска связности в `hot_swap` мертва: проверка имён срабатывает раньше, а для сохранённых функций ни одно ребро не считается «затронутым».
6. «Weakening check» сводится к «имя функции осталось»; контракты, guard'ы и побочные эффекты не сравниваются.
7. Ownership-анализатор существует только как документ. Документированная компиляция `Transfer` при `from == to` создаёт деньги из ничего (1000 → 1300).
8. Таблица антиподов GERMES неверна в двух парах из трёх (пары на 60°, а не на 180°).
9. Lineage: хэш содержимого не включает родителя — поколения с одинаковым кодом получают одинаковый `content_hash`.
10. Три алфавита Star Gate (Unicode / enum / клавиши шрифта) разошлись; `$` и `%` — не рёбра; `→` и `▲` не имеют клавиш.
11. Base64-«сайдкары» шрифтов — 11-байтовые заглушки `placeholder`; `install-fonts.sh` их не декодирует; клавиатура в репозитории неработоспособна без внешних файлов.

**Что сделано в ветке.**

- Аддитивный фикс сборки (`extern crate self as ail_mvp;`) — библиотека и демо v1 собираются и запускаются.
- `mvp/src/v2/` — параллельная реализация (12 модулей, 55 тестов, clippy-чистая): канонический алфавит с парсером M2M, вычисленная геометрия GERMES, Binary AST в библиотеке с типизированными параметрами и `Call`, символьное извлечение контрактов, проверка refinement вместо проверки имён, статический ownership-анализатор с обязательствами и runtime-проверкой алиасинга, граф связей **выводимый из кода**, монотонная трёхкомпонентная модель насыщенности, Merkle-lineage с верификацией, метрики здоровья (transitivity + lever), актор с отчётом о swap вместо `println!`.
- `cargo run --bin v2-demo` — сквозная демонстрация; `.github/workflows/ci.yml`, `.gitignore`, `Cargo.lock`.

**Рекомендация.** Принять v2 как ядро следующей итерации, v1 оставить как замороженный исторический слой (его файлы не трогались). Приоритеты дорожной карты — в `04-v2-proposal.md`.

## Как проверить

```bash
cd mvp
cargo test                 # 55 тестов v2 + 1 тест v1
cargo run --bin ail-mvp    # демо v1 (теперь собирается)
cargo run --bin v2-demo    # демо v2
cargo clippy --lib --bins  # 0 предупреждений
```
