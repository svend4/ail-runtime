# 03 — Практический и технологический аудит

## 1. Процесс разработки

- **История.** 30 коммитов, все датированы 2026-07-23 (один день), один автор. Нет веток, PR, issue, тегов, релизов.
- **Темп против проверки.** Коммиты «Step N ✅» следуют друг за другом без запуска сборки (см. 02 §T1–T2). Это главный процессный риск: статусные документы отражают намерение, а не состояние.
- **Расширение области.** После ядра (AST → граф → риск) проект ушёл в шрифты, клавиатуру, RAG-макросы — при неработающем ядре. Каждая из этих веток разумна, но очередность инвертирована.
- **Языки.** Документы смешивают русский и английский; код — английский. Для внешних читателей стоит выбрать один язык спецификации (английский) и держать русский как перевод, или наоборот — но единообразно.

## 3. Технологический стек

| Выбор | Оценка | Комментарий |
|-------|--------|-------------|
| Rust 2021 | уместен | Ownership-модель естественно выражается; `Result` вместо исключений |

| Отсутствие `wasm-bindgen` | пробел | Единственный способ связать HTML-клавиатуру с runtime без сервера |

## 4. Инструменты: клавиатура и калькулятор

**Что есть.** Два HTML-файла: простая клавиатура (`stargate-keyboard.html`) и «научный калькулятор» с раскладками EN/RU, дуальными клавишами «буква ↔ глиф», 22 макросами и переключением шрифтов.

**Оценка UX.** Раскладка логична (ряд алфавита Star Gate окрашен по D1/D2/D3, макросы как F-клавиши). Но:

1. Нет связи с runtime: `Bal`, `Rsk`, `Swp` вставляют текст; результата нет.
2. Дуальная таблица `DUAL` сопоставляет *28* буквам *9* глифов с повторами (`Q→"`, `P→"`, `Z→"`), т. е. это не биективная кодировка, а подсказки.
3. Шрифт недоступен → экран показывает ASCII `"#'*&$()%`, что противоречит тезису «реальные глифы на клавишах».
4. Нет экспорта/импорта M2M-строк, нет истории.

**Что сделано в v2.** Парсер M2M (`v2::alphabet::parse`) и построение графа из текста (`RelationGraph::from_m2m`) — ровно та часть, которой не хватало. Мост в браузер (WASM) — в дорожной карте.

## 5. Шрифты Solan

- Файлов `.ttf` в репозитории нет; `.b64` — заглушки. Пока шрифты не опубликованы с лицензией, вся «печатная» часть концепции (M2M-строки как «читаемые человеком с шрифтом») не проверяема третьими лицами.
- Таблица клавиш (`font-stargate-map.md`) описывает глифы словами («sparse horizontal stripes», «diamond lattice»). Нужна спецификация глифов (SVG или bitmap) в репозитории — тогда шрифт можно пересобрать из спецификации (`fontforge` скриптом), а не хранить бинарник.
- Два отсутствующих глифа для `→` и `▲` — предложены клавиши `>` и `!` (`v2::alphabet::TABLE`); `.` зарезервирована под `·`.

## 6. Документация

**Сильно:** много коротких тематических документов, таблицы, примеры `.ail`, ASCII-схемы.

**Слабо:**

- нет оглавления и порядка чтения (README ссылается на три документа из 22);
- статусы разъехались (README vs IMPLEMENTATION_STATUS vs steps);
- нет глоссария (saturation / degree / marginality / lever / pheromone / weight — используются взаимозаменяемо);
- формулы даны в трёх вариантах без указания, какой — нормативный;
- ссылки на литературу без библиографических данных.

В ветке добавлены: индекс аудита, спецификация v0.2 с глоссарием и нормативными формулами.

## 7. Зрелость (сводно)

| Критерий | Уровень |
|----------|---------|
| Собирается из чистого клона | нет → да (ветка) |
| Тесты покрывают заявленные свойства | нет → да для v2 |
| Демо соответствует документам | нет → да для v2 (`v2-demo`) |
| Есть CI | нет → да (ветка) |
| Есть версионированная спецификация | нет → v0.2 (ветка) |
| Внешний пользователь может повторить сценарий | нет → частично (шрифты по-прежнему внешние) |

Итог: до ветки — **демо-прототип без воспроизводимости**; в ветке — **MVP-кандидат ядра** (v2) + замороженный v1.

## 8. Риски проекта

1. **Фактор автора.** Весь код и концепция — одного человека; знание не зафиксировано в тестах/спецификации (частично исправлено в ветке).
2. **Теоретическая переоценка.** Апелляции к jamming/Рамсею могут быть восприняты как необоснованные претензии; лучше явно называть их эвристиками до появления формальных результатов для малых графов.
3. **Разрастание без ядра.** Клавиатура, шрифты, RAG — потребители API, которого ещё нет. Рекомендация: заморозить расширения до стабилизации `v2::actor`.
4. **Лицензии.** Шрифты и будущие внешние ассеты — проверить права.
